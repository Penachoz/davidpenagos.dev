# 4. UAO: práctica, pasantía y grado

La información oficial de la UAO distingue:

- **Práctica Profesional:** asignatura obligatoria y requisito de grado; dura seis meses calendario, jornada completa (mínimo 40 horas semanales) y exige empresa formalizada en el sistema UAO.
- **Pasantía Organizacional:** modalidad opcional de Trabajo de Grado para resolver un problema específico de una empresa, con plan aprobado y acompañamiento académico.
- Si el programa incluye obligatoriamente **Práctica y Trabajo de Grado**, el mismo ejercicio no puede ser reconocido por ambos, aunque pueden ser complementarios.
- Para pasantía institucional en Ingeniería, la información publicada menciona 107 créditos aprobados para planes 2020 y 122 para planes 2013.

# 9. Entrevistas: lo que debes poder demostrar

## Linux

- Procesos, memoria, disco, permisos, systemd y logs.
- DNS, TCP, HTTP/TLS, puertos, rutas, NAT y balanceo.
- Bash y Python para automatizar una tarea.

## Git y CI/CD

- Branch, commit, merge/rebase, pull request y rollback.
- Pipeline: lint, test, build, scan, publish, deploy.
- Secrets, OIDC y environments.

## Terraform

- State, backend, locking, modules, variables, outputs y drift.
- Diferencia entre plan/apply/import/move/destroy.
- Cómo evitar secretos y cambios destructivos.

## AWS

- IAM, VPC, EC2, ECS, Lambda, S3, RDS, DynamoDB.
- ALB/NLB, Auto Scaling, CloudWatch, Route 53.
- Alta disponibilidad, backups, RTO/RPO y costos.

## Conductual

Prepara historias STAR sobre:

- Un fallo difícil que diagnosticabas.
- Aprender una herramienta por tu cuenta.
- Atención a una persona bajo presión en call center.
- Un desacuerdo o error y qué cambiaste.
- Cómo organizas trabajo cuando no tienes instrucciones.

# 10. Qué significa “bien pagado”

No optimices el primer empleo solo por salario. Evalúa:

1. ¿Tocarás infraestructura o solo tickets repetitivos?
2. ¿Hay mentor y revisión de cambios?
3. ¿Usan Git, Linux, cloud, IaC, CI/CD y observabilidad?
4. ¿Participarás en incidentes y postmortems?
5. ¿El rol permite crecer a junior y luego cambiar al mercado remoto?

Tu inglés C1 puede multiplicar oportunidades, pero primero necesitas evidencia técnica y experiencia laboral. El camino más seguro hacia una remuneración alta es:

**práctica técnica → ownership de servicios → infraestructura como código → incidentes/observabilidad → mercado remoto internacional**.

No existe una certificación que salte esas etapas.
