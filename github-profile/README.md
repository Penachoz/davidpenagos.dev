## Three cloud builds

1. **CineCine Cloud Platform — building now:** secure the REST API, add tests and containers, then deploy to AWS using Terraform, GitHub OIDC and observability.
2. **MediSync Cloud API — next:** rebuild the appointments backend with API contracts, secret management, backups and Azure Container Apps.
3. **Edge Safety Cloud — planned:** connect the Raspberry Pi detector to AWS IoT, an event pipeline, dashboards, alerts and a recovery runbook.
