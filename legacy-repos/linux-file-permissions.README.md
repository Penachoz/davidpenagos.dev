# Linux file permissions

Lab: inspect and correct file and directory permissions with `ls` and `chmod` so a simulated org matches least privilege.

Framed as **systems administration**, not as a Coursera “security professional” persona.

## What I practiced

- Reading `rwx` bits and umask implications
- Fixing group vs other access
- Documenting before/after so a second operator can audit

## Commands

`ls -l` · `chmod` · `chown` / `chgrp` where needed
